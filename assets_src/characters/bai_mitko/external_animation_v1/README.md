# Bai Mitko External Animation v1

This is the current active Bai Mitko animation import path.

It uses external ZIP exports containing EAST walk start/loop/stop sprite images plus JSON metadata. WEST is mirrored from EAST. North, south, and diagonals are intentionally deferred until east/west is good.

Source-of-truth rule: Ludo JSON metadata defines frame rectangles, order, frame count, and timing when available. The active runtime uses one sheet image per animation and draws the current JSON frame rectangle with canvas transforms. The importer does not guess grids unless metadata is missing or unusable.

The source ZIPs and unpacked Ludo.ai sheets are preserved unchanged. Runtime staging and previews are derived from those sheets and apply a soft green-dominance alpha cleanup: pixels become transparent based on how strongly green they are, not only when they exactly match `#00ff00`. Semi-green edge pixels get partial alpha and green spill suppression so outlines and character colors survive.

## Folders

- `input/` - copied external ZIP exports.
- `unpacked/` - unmodified ZIP contents, separated by animation.
- `previews/` - generated GIF/contact-sheet review outputs with preview-only checker backgrounds.
- `runtime_staging/` - unused by the current direct-sheet path; ignored if generated by older experiments.
- `reports/` - JSON inspection, preview, staging, and cleanup reports.

Game-facing cleaned start/loop/stop sheets are emitted to:

```text
assets/chapter1/characters/bai_mitko/walk_east_start.png
assets/chapter1/characters/bai_mitko/walk_east_loop.png
assets/chapter1/characters/bai_mitko/walk_east_stop.png
```

The same build step also soft-cleans the existing `idle*.png` files in that runtime folder.
